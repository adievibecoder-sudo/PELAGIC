# CIE datasets

Unmodified official CSVs and metadata, accessed 20 October 2026.

- CIE (2019), Colour-matching functions of CIE 1931 standard colorimetric observer. DOI: https://doi.org/10.25039/CIE.DS.xvudnb9b
- CIE (2019), CIE standard illuminant D65. DOI: https://doi.org/10.25039/CIE.DS.hjfjmt59
- Source: https://files.cie.co.at/Publications-datasets/ (exact filenames retained).
- License: CC BY-SA 4.0, https://creativecommons.org/licenses/by-sa/4.0/ . Metadata includes checksums and attribution. These datasets retain their own license, separate from project MIT code.

`tests/phase0-optics.mjs` verifies both published MD5 values before use. Its derived numerical colour tables retain CC BY-SA 4.0 attribution to these datasets; they are diagnostic data, not production shader coefficients.
