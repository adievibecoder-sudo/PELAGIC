# Independent cloud morphology control

24 October 2026. A continuation only; no adoption or owner acceptance.

Measured view integration converges while the repeated inflated silhouettes persist. The convective, bank and condensate procedural alternatives failed shape validation. A different falsifying control uses an independently authored 3D density grid under unchanged PELAGIC light transport, atmosphere, waves and exposure. `maCloud=volume` is opt-in.

Source: [Walt Disney Animation Studios Cloud Data Set](https://www.disneyanimation.com/resources/clouds/), Copyright 2017 Disney Enterprises, Inc., [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Its photographic reference is Kevin Udy's [26 July 2012 cumulus](https://coclouds.com/436/cumulus/2012-07-26/). This is an authored volume based on a photograph, not measured liquid water or a numerical atmosphere. The official archive's sixteenth-resolution member was retrieved by bounded HTTP ranges, verified against archive size/CRC, then SHA-256 recorded. No third-party rendered image is used as PELAGIC evidence.

Conversion: installed OpenVDB binding, one-voxel zero padding, original 128:88:156 padded aspect ratio, float16 density, conservative cell-average mipmaps. Payload4,016,058 bytes; quantized mean error below1e-5 at every mip. Attribution, modification description, original README and source/derived hashes accompany the asset. Derivative asset retains CC BY-SA 3.0; original PELAGIC shader code is separate.

Placement is a diagnostic:3.6 km cells, fixed seed hashes, independent horizontal orientation, height1.2-1.5 km at the established1.5 km layer depth. Uniform scale preserves the exemplar aspect ratio. Coverage controls instance strength; all cloud consumers share the same advected volume. Original extinction/light integration remains exact. Expected limitations: one repeated exemplar, empirical scale and occupancy, static shape translated with wind, low-resolution boundary and density-filtering errors. Pure stratus/storm remain preserved. Do not claim calibrated cloud water, equal occupancy, a production weather replacement or equal-quality speedup.

Reject promotion if silhouettes remain artificial, if a repeated exemplar dominates, or if integration creates incompatible shadows/reflections. First compare daylight near/elevated, low Sun, raw optical-depth distribution and existing rebase/advection checks. A substantial improvement would still require complete four-view motion/cost evidence and owner review.
